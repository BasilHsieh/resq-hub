
# UpdatedAt

一筆狀態最後一次有人更新的時間，只有一種寫法。

- **寫法**（D-16）：今天「最後更新 14:26」；前一天「最後更新 昨天 08:40」；更早「最後更新 9/24 08:40」；從來沒有人回報「還沒有紀錄」。
- **不要**：「1 小時前」「剛有人問過」這類口語。現場的人看不懂，也分不出講的是同意還是需求。
- **`at`** 收 Date、ISO 字串、毫秒，或已經寫好的「14:26」「昨天 08:40」「9/24 08:40」（mockup 用）。`now` 可以指定「現在」，預設是手機的時間。
- **顯示哪一筆的時間**由規格決定（資料模型 §0d），元件只負責寫法。同一個函式也匯出成 `ResQ.formatUpdated(at, now)`，給資料層用。
