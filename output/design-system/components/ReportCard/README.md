# ReportCard

回報頁上的一塊：「屋主同意嗎」或「需要人嗎」，寫現在的值、最後更新，和一顆更新鍵。

- **兩塊各自獨立**（D-16）：同意和需求各自回報、各自顯示最新一筆；只知道其中一項的人，只更新那一項。公共區域只有需求那一塊。
- **不是線性流程**：不先問同意再問需求，也不因為還沒同意就擋住需求。
- **`emphasis`**：剛更新完同意、下一步最可能是需求時，那一塊加一圈主色框、按鈕變主要。一個畫面最多一塊。
- **文字不開放改**：欄名與按鈕字（更新同意狀態、更新需求）是固定的。
- **Props**：`kind`（`consent` 或 `need`）、`status`、`count`、`updatedAt`、`emphasis`、`onClick` 或 `href`。
