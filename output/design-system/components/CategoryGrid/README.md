# CategoryGrid

清單頁最上面的四個分類：大數字色塊，點一格，下面只列那一類。

- **四類照「現在該做什麼」分**（D-16）：可以直接幫忙（已同意＋公共區域，預設）／要先問屋主（尚未取得同意）／不同意／暫時不用去（人夠了、清完了）。
- **為什麼放最上面、數字這麼大**：真實規模是上千戶，往下分段排的話，下面那段永遠滑不到。數量讓人不點進去也知道每一類有多少。
- **選中的那一格**是主色加一個勾（不只靠顏色）；其他是淺色塊。
- **下面的說明框**跟著選中的分類換，告訴人到了該做什麼；`showHint` 設成 false 可以關掉。
- **數量只算附近**（走路 15 分鐘內），跟下面的清單一致。
- **文字不開放改**：四個分類的名字是 D-16 的決定。
- 🚧 預設停在「可以直接幫忙」還是「要先問屋主」，交給兵推測（D-15 的取捨）。
- **Props**：`value`、`counts`（或 `countHelp` `countAsk` `countDeclined` `countDone`）、`onSelect(key)`；mockup 串頁用 `hrefs`（或 `hrefHelp` 等四個）。
