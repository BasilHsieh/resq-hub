# HouseholdRow

清單上的一戶：一張卡片，第一行地址與走路時間，第二行同意與需求，第三行最後更新；點一下就地展開，給「怎麼走」和「回報這一戶」。

- **一戶一張卡**（D-16）：要找得到「巷子的巷子」就要門牌，不按巷子合併。
- **同意和需求分成兩個標籤**，不混成一個。「不同意」的戶不顯示需求。
- **排序由頁面決定**：同一分類內照走路距離，近的在前；不替志工決定哪一戶重要。
- **展開**：不另開一頁，卡片加一圈主色框。說明句跟著同意狀態換，尚未取得同意是「到了先敲門，問屋主需不需要幫忙」。兩顆膠囊按鈕：怎麼走（次要）、回報這一戶（主要，比較寬）。
- **按鈕叫「回報這一戶」，不叫「我到了」**：到了是時機，回報才是動作。一戶要做兩三天，到了就要回報，不能等做完。
- **地址一律虛構**（甲街、乙路）：同意狀態不能掛在真實地址上。
- **Props**：`address` `consent` `need` `needCount` `updatedAt` `walkMinutes` `expanded`；`onSelect` 或 `href`、`onDirections` 或 `directionsHref`、`onReport` 或 `reportHref`；`hint` 可以換掉展開後那句說明。
