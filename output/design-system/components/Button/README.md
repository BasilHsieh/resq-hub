# Button

一個按鈕做一件事，字寫動作。

- **四種**：`primary`（主色，這個畫面最可能按的那一個，一個畫面最多一顆）／`tonal`（淺色塊，其他答案；舊名 `outline` 也收）／`dashed`（虛線，「還沒確定」的那個答案，例如還沒問到）／`link`（離開這個畫面，例如回到清單）。
- **兩種大小**：`lg` 是一題一頁的答案按鈕，靠左排，圖示放在左邊的白圓裡，72px 高、有副標時 88px；`md` 是卡片裡的膠囊按鈕，56px。任何可以按的東西至少 48px（戴手套）。
- **副標 `sub`** 只給 `lg`：一句話說明這個答案包含哪些現場情況。
- **答案放在畫面下方**，垂直排、一個答案一顆，大拇指按得到。
- **字寫動作**：「回報這一戶」，不是「我到了」；「更新同意狀態」，不是「編輯」。一顆按鈕不做兩件事（不做「同意，還要人」）。
- **圖示一定跟字一起**，名稱見 Icon。
- **Props**：`variant` `size` `icon` `sub` `children`、`onClick` 或 `href`。
