# NeedChip

一戶現在還要不要人：缺 N 人、人夠了、清完了、需求不明。

- **用在**：清單上每一戶（在同意標籤旁邊）、回報頁「需要人嗎」那一塊。
- **值**：`need`＋`count`（缺 5 人；`10+` 寫成「缺 10 人以上」）／`enough` 人夠了／`done` 清完了／`unknown` 需求不明（只是字，不做成標籤）。沒給 `status` 就什麼都不畫。
- **暖色只給缺人**：杏橘色塊加人形圖示，是全畫面唯一的暖色，清單上第一眼跳出來的就是它。人夠了、清完了用淺色塊；對要挑下一戶的人，兩者的答案一樣：暫時不用去。
- **何時不顯示**：「不同意」的戶不顯示需求；「尚未取得同意」的戶，需求不知道就不寫（鄰居說缺 5 人，就照寫）。
- **只講人力**。物資（便當、水）不放在這裡：物資若廣播需求，五路人馬會各送一份（U-06，待驗證）。
