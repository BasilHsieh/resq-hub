# Icon

十一個線條圖示（Tabler Icons，MIT 授權），線寬 2、24px 格，顏色跟著字。

- **名稱**：`back` 返回／`check` 已同意、已記下、清完了／`close` 不同意／`clock` 還沒問到／`walk` 走路幾分鐘／`directions` 怎麼走／`report` 回報這一戶／`user-plus` 還要人／`users` 缺人、人夠了／`info` 說明／`lock` 不用登入。
- **一定跟字一起**：圖示是輔助，不是語言。唯一的例外是返回鍵，它有 `aria-label`。
- **不用 emoji**。要新的圖示先從 Tabler 找，線寬與格子要一致。
- **Props**：`name`、`size`（預設 24）、`label`（單獨出現時必填）。
