# ConsentBadge

一戶的同意狀態：已同意、尚未取得同意、不同意，或不需要同意的公共區域。

- **用在**：清單上每一戶、回報頁「屋主同意嗎」那一塊。
- **四種值**（D-16）：`agreed` 已同意（主色淺色膠囊＋勾）／`pending` 尚未取得同意（虛線膠囊）／`declined` 不同意（實線膠囊）／`public` 公共區域（淺色塊）。沒給值就是尚未取得同意：沒有紀錄的戶本來就是這個狀態。
- **形狀帶意思**：虛線＝還沒確定，實線框＝確定的「不」，填色＝確定的「是」。顏色從不單獨表意，每一種都有字。
- **「已同意」涵蓋三種現場情況**：屋主或家人說好、裡面已經有人在做、帶隊的人叫你進去。它是給下一個人看的資訊，不是進門許可；到了門口仍要打招呼。
- **不要**：跟需求合成一個標籤（「同意，還要人」）；寫原因（「沒人應門」）；寫「沒人在家」「空屋」，那不是狀態。
